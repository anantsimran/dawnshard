Dawnshard

A training system built to make experiments inspectable.

A reusable loop connects explicit training state to model-specific policy. In the Multi30k pipeline, custom probes capture attention during evaluation, while per-sample seeds keep validation masks stable across passes.

What to inspect

Three decisions that shape the system

These are the parts worth opening in the source: where the loop can be extended, what a probe can see, and how evaluation stays comparable.

01 / Architecture

State, policy, mechanism

TrainState owns the model and optimizer. EpochSpec provides metrics and probes. fit runs both without a model-specific trainer.

Inspect the contracts {% include ".icons/material/arrow-up-right.svg" %}
02 / Inspection

Probes at batch time

A probe receives the model, batch, detached prediction, and run position. The attention probe saves maps from the evaluation forward pass, without another pass through the model.

See the attention probe {% include ".icons/material/arrow-up-right.svg" %}
03 / Evaluation

Stable masks, useful comparisons

Training draws new masks each batch. Validation uses a local generator seeded by sentence index, so a sentence keeps the same mask across epochs without drawing masking randomness from the global generator.
