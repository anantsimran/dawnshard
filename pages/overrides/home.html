Dawnshard

A top-down–designed ML infrastructure library.

One training API accepts models and loaders that meet its batch contract. Explicit state, supplied policy, and named functions keep the loop reusable; tests guard the package boundaries, and each run leaves evidence to inspect.

Design choices

The principles live in the code

Each choice has a defined home in the library and a place to check its effect.

01 / Architecture

Separate state, policy, and mechanism

TrainState holds mutable resources. EpochSpec supplies scoring and probes. fit executes the run for any matching model and data.

Trace the separation {% include ".icons/material/arrow-right.svg" %}
02 / Extension

Give each concern one home

Metrics score outputs, probes inspect a batch, and checkpointing stays a named function. A new concern has a clear place to enter.

Find the extension points {% include ".icons/material/arrow-right.svg" %}
03 / Boundaries

Make dependencies directional

Each package owns one concern. A test rejects forbidden imports and cycles; source checks enforce named arguments and docstrings.

Inspect the checks {% include ".icons/material/arrow-right.svg" %}
04 / Observability

Leave evidence behind

Epoch records and run history retain metrics, seeds, the Git revision, and machine context. Local plots and probes help explain the numbers.
